Pinceaux et couleurs
Couleur active : #00f2ff
Détection et mouvements

Pince pouce-index pour dessiner. Écarte les doigts pour déplacer la main sans peindre. Le cercle cyan indique la main suivie, le rose indique le dessin.

Mode d'emploi

Sans caméra : dessine avec ton doigt sur l'écran ou avec la souris.

Avec caméra : autorise la caméra frontale, puis rapproche pouce et index pour peindre. Le suivi lisse les tremblements et ajuste la sensibilité à la taille de ta main.

Mouvements : active « Main ouverte : rotation » pour orienter l'œuvre en déplaçant la paume sans pincer.

Exports : PNG pour une image, GLTF pour réutiliser les objets 3D dans Blender. Les commandes vocales peuvent changer la couleur, effacer, annuler ou exporter.

Confidentialité : la peinture et l'analyse des mains s'effectuent dans le navigateur ; l'assistant Mistral est optionnel et transmet uniquement les messages saisis quand il est activé.

Gratuit sans clé IA. Caméra optionnelle. Fonction AR selon l'appareil.
